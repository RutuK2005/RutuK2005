# Hi, I'm RutuK2005

I'm building practical software and documenting the engineering decisions behind it.

### Current project: Android backups on Windows

I'm developing a consumer backup product for photos, videos and selected files, starting with Pixel 7 and Windows 11. The Windows preview supports verified USB imports, readable backup history, optional encrypted archives and checksum-checked recovery, plus a native Android Wi-Fi companion.

The 0.8 milestone focuses on old photo collections: exact-duplicate consolidation, ordinary Year/Month folders, a scrolling Memories gallery, video playback, optional automatic local people grouping, names/hiding/favorites, and Google Takeout metadata import. Originals remain untouched. I document fixture results separately from unfinished real-device, large-library, face-accuracy and commercial release validation.

Product source is private. The [public engineering showcase](https://github.com/RutuK2005/phone-backup-showcase) has architecture, a synthetic interface screenshot, test scope and dated development notes.

### What I'm working with
