# Hi, I'm RutuK2005

### Current project: Android backups on Windows

I'm developing a consumer backup product for photos, videos and selected files, starting with Pixel 7 and Windows 11. The current developer preview combines a native C#/.NET desktop interface, verified USB imports, encrypted backups and checksum-verified restore.

The current 0.4 preview adds a native Android Wi-Fi companion, certificate-pinned pairing, incremental file transfers and opt-in unattended setup alongside the organized library and resumable USB workflow. The actual Java client passed a Windows receiver backup/restore interoperability check. Physical Android permission/background acceptance and battery/large-library profiling are next; I keep those distinct from fixture test results.

Product source is private. Explore the [public engineering showcase](https://github.com/RutuK2005/phone-backup-showcase) for architecture, screenshots, test scope and development notes.
